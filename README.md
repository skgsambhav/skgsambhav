### 👨‍💻 About Me

I am a **Systems Engineer, Algorithmic Trader, and Full-Stack Architect** with a passion for building robust production software, automated IoT hardware, and quantitative financial engines.

- 🛠️ **IoT & Embedded Hardware:** Engineering zero-latency dual-node security systems using **ESP-NOW 2.4 GHz Direct Radio**, active-low relay drivers, captive portals, and cloud sync.
- 📈 **Quantitative Trading & FinTech:** Architecting automated **Options F&O momentum systems** with sub-second execution, smart trailing stop-losses, and real-time risk dashboards.
- 🏢 **Enterprise SaaS & ERP:** Developing desktop-grade double-entry commercial accounting ERPs, inventory managers, and multi-tenant platforms.
- ☁️ **Cloud Infrastructure:** Deploying scalable containerized microservices on **Docker, Nginx Proxy Manager, FastAPI, and Linux VPS**.
